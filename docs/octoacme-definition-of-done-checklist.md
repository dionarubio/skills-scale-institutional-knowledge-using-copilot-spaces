# OctoAcme — Definition of Done Checklist

Use before moving backlog items to **Done** and before release sign-off.

## Scope & Acceptance
- [ ] User story/problem statement is complete.
- [ ] Acceptance criteria are fully met.
- [ ] Out-of-scope items are documented.

## Quality & Security
- [ ] Required tests are added/updated and passing.
- [ ] CI checks are passing.
- [ ] Security and dependency checks are complete.
- [ ] No known critical/high defects remain.

## Documentation & Communication
- [ ] User-facing/internal docs are updated as needed.
- [ ] Release notes impact is captured.
- [ ] Stakeholders are informed of changes.

## Operational Readiness
- [ ] Monitoring/logging updates are in place (if applicable).
- [ ] Rollback or mitigation plan is documented.
- [ ] Post-release validation steps are defined.
