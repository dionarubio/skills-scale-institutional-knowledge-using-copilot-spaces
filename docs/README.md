# OctoAcme Project Management Docs

This directory contains OctoAcme's project management playbook for running cross-functional work from kickoff through continuous improvement. The process emphasizes clear ownership, iterative delivery, measurable outcomes, proactive risk management, and consistent stakeholder communication.

At a high level, OctoAcme projects move through initiation, planning, execution and tracking, release and deployment, and retrospective learning, with defined roles and communication practices throughout.
