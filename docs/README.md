# OctoAcme Project Management Docs

This directory is the single entry point for OctoAcme project management processes, templates, and checklists.

## Lifecycle Summary
1. **Initiation**: clarify problem, outcomes, stakeholders, and go/no-go.
2. **Planning**: define scope, backlog, milestones, dependencies, and DoD.
3. **Execution & Tracking**: deliver in iterations, manage blockers, track outcomes.
4. **Risk & Communication**: maintain visibility on risks, owners, and stakeholder updates.
5. **Release & Deployment**: verify readiness, deploy safely, and communicate clearly.
6. **Retrospective**: capture learnings, assign actions, and improve the process.
